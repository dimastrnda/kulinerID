# Kuliner.ID

Kuliner.ID is a web-based culinary information system developed as an academic project at Universitas Amikom Yogyakarta.

## Features

- User Authentication
- Culinary Information Management
- Category Management
- CRUD Operations
- Responsive User Interface

## My Role

- Developed both frontend and backend features
- Designed database structure
- Implemented CRUD functionality
- Tested application features
