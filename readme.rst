# Kuliner.ID

Kuliner.ID is a web-based culinary information system developed as an academic project at Universitas Amikom Yogyakarta.

## Features

- User Authentication
- Culinary Information Management
- Category Management
- CRUD Operations
- Responsive User Interface

## Tech Stack

- PHP
- CodeIgniter 3
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap
